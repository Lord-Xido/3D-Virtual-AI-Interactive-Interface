# Project Status

**Last reviewed:** 2026-07-29  
**Classification:** experimental visual-computing repository

## Status definitions

| Status | Meaning |
|---|---|
| Merged reference demonstration | executable on `main`, validated for its documented invariants |
| Draft integration candidate | implemented in a pull request, not part of `main` |
| Legacy demonstration | retained for history; not the recommended starting point |
| Proposed | documentation or concept without a canonical merged implementation |

## Claims not made

The repository does not currently establish:

- artificial general intelligence;
- consciousness;
- production-grade autonomous agents;
- dense rendering of billions of voxels or tensor cores;
- physical quantum hardware from QSOL terminology;
- optimization of an unspecified external objective;
- direct physical hardware equivalence for virtual machine diagrams;
- secure execution of hostile content;
- internet crawling or model inference unless explicitly connected and documented.

## Promotion checklist

A draft engine may merge when it has:

- [ ] a bounded runtime and resource contract;
- [ ] deterministic initialization or a documented stochastic test protocol;
- [ ] responsive resize and browser lifecycle handling;
- [ ] capability checks for browser or native APIs;
- [ ] an executable validator or focused tests;
- [ ] snapshot, trace or benchmark evidence;
- [ ] implemented-versus-proposed documentation;
- [ ] no unresolved conflict with canonical merged engines;
- [ ] green CI and completed review.
